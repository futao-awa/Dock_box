# 2026-10-13 修复与功能更新

- 透明背景从 HTML、body 到 Electron 窗口统一初始化，避免 Dock 和分类周围出现白色矩形。
- 新增透明堆叠列表，保留网格、普通列表与扇形；已有配置可在动效与交互中切换。
- Windows Shell 启动桥接支持快捷方式、系统工具、文件夹、网址和商店应用。保留启动参数与工作目录；失焦只隐藏分类，不销毁正在请求启动的渲染器。
- 原生桥接显式使用 UTF-8 输入输出，修复中文路径和参数被系统代码页破坏导致的启动失败。
- 应用识别合并开始菜单、桌面与 AppsFolder，自动提取图标；手动路径、图片仍可使用。
- 任务栏取消对不可用 Accent 读取接口的强制依赖，支持 Windows 11 Backdrop；退出清除自定义样式并恢复系统主题。
- 圆角遮罩显式初始化 layered alpha，采用 DPI 感知位置并持续保持置顶。
- 管理界面采用灰绿底色、清晰文字；应用、分类和图标管理使用独立窗口。
- 右键添加刷新和任务管理器；渲染进程异常可重建 Dock。
- 管理面板添加 U 盘检测、系统接口启动、联网禁用、名称 / 字体 / 倒影、触发条颜色与可关闭的开机动画。
- 启动先创建 Dock，再连接原生服务；设置页按需加载；应用扫描异步并发；分类复用窗口。

验证：27 项单元测试、TypeScript 检查、生产编译以及隔离配置的 Electron 桌面回归。UTF-8 修复后的应用库在当前机器识别 234 个应用。额外的真实 Windows Shell 测试确认 EXE 和快捷方式能启动，并保留中文、空格、启动参数和工作目录。桌面回归抑制外部程序实际启动和系统修改，不等同于任务栏、圆角、多屏、真实登录自启、U 盘硬件和防火墙 UAC 的人工验收。
